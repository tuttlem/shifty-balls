# Desktop First-Course Contract

## Invocation

```text
cargo run
```

The application opens directly into one course attempt, with a single ball at
the defined start.

## Controls

| Input | Behaviour |
|---|---|
| W/A/S/D | Existing world-relative internal-mass shift controls |
| R | Immediately restore a fair fresh attempt while keeping the session best |
| F3, if supplied | Toggle development-oriented mass, velocity, and timing display |

## Observable course contract

1. The player sees a forgiving descent before a readable gentle bend.
2. A later stronger bank gives a visible high/low line and recoverable poor
   positioning.
3. A compression and crest make the prior line and preserved momentum matter.
4. The final apron and finish are obvious before the player reaches them.
5. The display makes current or completed time, session best, speed, and
   existing internal-mass state available without a production HUD.
6. R returns position, orientation, motion, mass state, timing, and view to a
   fair start quickly.
7. Finish completes an active attempt once, freezes its completed time, and
   only improves the best when faster.
8. No input directly steers, propels, reorients, or applies arbitrary lateral
   movement to the ball.

## Kill-test record

After repeated trials, document an affirmative, negative, or unresolved result
for prediction, improvement, climbing/descending banks, height versus speed,
momentum through turns, recovery, repeated interest, satisfaction from faster
runs, and player responsibility. Completion alone is not a positive result.
